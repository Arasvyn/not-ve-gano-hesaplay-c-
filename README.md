# AKTS & GANO Not Hesaplayıcı

Üniversite öğrencileri için geliştirilmiş, HTML, CSS ve JavaScript tabanlı dinamik ve modern bir dönem sonu not ve GANO hesaplama uygulaması.

## Özellikler
- Dinamik ders ekleme ve silme.
- Vize ve Final ağırlıklarını (yüzdelerini) özelleştirebilme.
- AKTS ağırlıklı Dönem Ortalaması (GANO / 4.00) hesaplama.
- Her ders için harf notu barajına göre Geçti / Kaldı durumunu gösterme.
- Modern Glassmorphism (şeffaf cam) ve blurlu akademik arka plan tasarımı.

## Teknolojiler
- HTML5
- CSS3
- JavaScript (ES6)

## Canlı Önizleme / Kullanım
`index.html` dosyasını tarayıcınızda açarak doğrudan kullanabilirsiniz. GitHub Pages üzerinden ücretsiz olarak canlıya alabilirsiniz.
